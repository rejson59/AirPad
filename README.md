# AirPad
Graj na swoim komputerze/laptopie lub jakimkolwiek większym ekranie w gry tak jak na konsoli! Używaj telefonu jako kontrolera! Wystarczy połączyć telefon z komputerem/laptopem poprzez 4 cyfrowy kod lub kod QR, wybrać grę i grać! Możliwość gier multiplayer i połączenia nawet kilku telefonów na raz!
